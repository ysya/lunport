## Behavior and limits

Leave full-pulls every selected available space, overlays cached dirty edits, refuses missing/unreadable/unknown active hosts and conflicting key authority, and recognizes retained legacy alias1 / Own1 source evidence. New fixed host IDs exclude all source/Local identities, selected jumps remap, Local rows/keys remain. Stable alias suffixes and all source fields/pins/annotations validate before passwords. Password namespace copies are zeroizing, individually checkpointed, differing existing destinations refuse, originals stay. Atomic latest-Local activation keeps a cleanup journal until current mnemonic deletion succeeds. Each cleanup effect uses fresh format proof; failed gate storage keeps latest gate in memory and save_blocked. No private export, legacy SSH writer, vault mutation or remote DELETE.

Rotation full-pulls all live account spaces including unselected, flushes ordinary selected dirty changes under caller-held lifecycle, requires relay freeze support and per-chain4096/1MiB budgets, then computes complete observed journal/target storage with maximum-width receipt sequences and8KiB reserved overhead before any staging/freeze. Freeze account first, re-enumerate membership, freeze all live child chains, checkpoint each accepted effect. Every source ciphertext authenticates bounded identity and zeroizes parsed secret JSON/bytes. Typed Host2/KeySlot2 records, tombstones, pins and revisions copy; opaque old/unknown kinds stay ciphertext. Destination Meta3 holds matching Publishing marker until all exact accepted receipts and full baselines are durable; future/foreign/invalid gates refuse. Full baselines cannot omit accepted rows or regress below accepted seq. Current mnemonic stays source until fresh source/target proofs and active release. Source archive supports retry if new-code promotion succeeds but state save fails. Local/Vault/private files/passphrases stay unchanged.

The source relay chains are frozen and retained; no source DELETE is implemented. Old code can still read historical frozen ciphertext, while future updates use the new code. Native/UI must not promise historical-read revocation. Client-side lifecycle/freeze protocol is not a server-wide atomic gate; remote changes racing freeze are re-read and may leave an honest pending operation. The budget precheck proves the observed snapshot; racing growth is bounded/rechecked after freeze and cannot report false complete. Root must decide any future destructive source cleanup separately.

Network cost: leave polls account then full selected-space baselines on each retry and rechecks account before credential effects. Rotation repeats full account proofs around checkpointed writes, copies every live space, and performs freeze/create/push receipts; unresolved gates intentionally cause extra polling rather than advancement. One scoped TDD pass, no repeated independent review requested, no dependencies added. Parent performs final native/UI/full-safe-suite gate after integration.
