## [1.4.0](https://github.com/ysya/lunport/compare/v1.3.0...v1.4.0) (2026-10-17)

Host cards now use two compact, equal-height lines: the host name, then SSH and its effective username. Short warnings stay aligned; address, port and further details are available in the hint and Host Details. Quick-connect actions appear on hover, focus or selection. Import hosts and New group are available from the menu beside New host.

Choose Lunport, Nord, Dracula, Catppuccin, Tokyo Night or Solarized in **Settings → Appearance**. Each palette supports System, Light and Dark mode, previews immediately and remembers your choice on this device. Sidebar, cards, dialogs and status colors use the same palette. Existing preferences retain the original Lunport palette, and external terminals keep their own themes. Theme sources and licenses are included in Appearance → Theme credits.
