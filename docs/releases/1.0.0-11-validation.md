## 本版行為

- Library sync 區分下載、資料不可用、身分衝突及重名錯誤。同名本機 host／Group 進入明確改名審核，保留 ID、路由、金鑰及雲端記錄；過期審核須重新整理，不猜測或合併記錄身分。
- 連線編輯器改用單一標題、固定底部操作列與單一表單捲動區，統一欄位尺寸並保護未儲存草稿。新增主機先 Create，儲存後才 Connect。
- Records MCP 新增 `create_host`：僅接受公開設定與既有參照；包含 Auto-log 在內都需要 SSHelter 明確審核，不隱含授予 AI 權限、信任指紋或登入。
- Records MCP 新增 `verify_host_key`；已儲存主機也可從 Server identity 核對。未知／變更指紋由 SSHelter 的既有獨立 Tauri host-key 視窗核准，MCP 不接受 trust answer。目的端握手後即停止，不需目的端登入金鑰、不登入、不執行命令。失效／被替換的核准不能回報已信任；Auto-log 的 `ssh_exec` 無互動及不自動信任規則維持。
- 更新後重新連線／重啟 MCP client，以重新取得工具清單。

## 限制

沒有取得使用者當時的正式同步資料，仍需其兩平台實際資料驗收；Windows WebView2 真人視覺互動驗收尚待完成。Library 的瀏覽器測試使用假 IPC／測試資料，沒有連到正式 relay。

保留 Beta 10 的 CoreAudio 啟動保護，可避免可偵測的啟動前故障變成無提示黑畫面；**沒有根除系統音訊死鎖**，也不能涵蓋檢查後才出現的 GPU／CoreAudio 停滯。音訊原始根因仍未確定，不能歸咎特定應用程式。既有睡眠喚醒、正式 app 更新／重啟與其他裝置驗收限制仍適用。

本次未安裝各平台套件、未操作使用者正式 app 的 updater，未修改正式 vault、MCP 權限、relay、WebKit defaults 或系統音訊服務。發布沿用現有建置與簽章流程。

不要重複 dispatch 此版號、覆蓋 tag，或以 stable 的平台重建 workflow 補建 Beta。

後續指紋核准與遷移後 Library sync 的可重現失敗路徑已隨 [Beta 12 修補](1.0.0-12-validation.md)。若遇同意後 `sync round superseded` 或舊版保留資料阻擋包含，請更新 Beta 12。
