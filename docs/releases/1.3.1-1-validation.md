# Lunport 1.3.1-1 Beta validation

This trial release publishes the compact host-grid changes from draft [PR #36](https://github.com/ysya/lunport/pull/36), source `1c59566f1117f8e91929b95ac1c7fecb18c09239`. The PR stays unmerged while the user tries the layout. Stable remains 1.3.0.

Only `src/components/records/HostList.tsx` and `src/components/records/library.css` change product behavior from 1.3.0. Cards use smaller responsive columns and gaps, natural content heights, combined address/port/user details and adjacent icon actions. Repeated server decorations and the separate SSH footer are removed. Warning text and tags share a compact metadata area; the grid shows one tag plus an additional-tag count with all names available to assistive technology and tooltips. IPv6 endpoints retain brackets. List mode retains its existing information and selection controls.

TypeScript, all 86 frontend files / 1,078 tests and the production frontend build pass locally. The exact source passes the [frontend/macOS/Linux suite](https://github.com/ysya/lunport/actions/runs/39056765867). Native sources, dependencies, updater public key, signing certificate and release workflows match the published 1.3.0 source. The full Windows suite was not retriggered for this TS/CSS-only patch; Windows packaging is checked by the Beta workflow.

The earlier compact iteration was reviewed in a browser at 360, 540, 860 and 1240 pixels, including list mode, selection, keyboard/actions, IPv6, disabled connections and the busy spinner. The final density revision's visual review was interrupted by an extension panel; this Beta is explicitly for hands-on feedback and does not claim completed native visual review. The Production App and its data were not opened or modified during release validation.

The Beta workflow stamps version 1.3.1-1 only in its CI workspaces. Committed application version fields remain unchanged. [Evidence and reproduction instructions](1.3.1-1-review/README.md) retain metadata and public signatures without installer payloads.
