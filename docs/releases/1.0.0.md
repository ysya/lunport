# SSHelter 1.0.0

- Manage hosts, Groups and keys in one Records library, with quick connect, searchable lists and shared details/editing workflows.
- Use SSHelter's SSH connection engine with explicit server identity, authentication and agent approvals. Public-key deployment includes a destination review and an authorization step.
- Sync the encrypted host library between devices and choose separately which private keys to share. Review imports and Legacy migration before applying them.
- Use the reorganized Settings window with Application, Workspace and Maintenance navigation, searchable sections and mode-specific categories. Legacy, Keychain, deployment, sync and maintenance dialogs share headings, scrolling and action bars.
- Get consistent sidebar, Group and detail transitions with System/Reduced motion preferences.
- Import a private key through the system file picker or paste it. File imports copy the chosen OpenSSH key into the local vault, keep the source file unchanged and stay on this device until you explicitly enable key sync. Extensionless files and supported encrypted OpenSSH keys are accepted; public keys, PuTTY and PEM formats are not supported.

Installers are available for macOS universal (Apple Silicon and Intel), Windows x64, and Linux x64/ARM64. This is a Stable release; it is also offered through the Beta update channel.

Existing Legacy workspaces retain explicit migration and sharing controls. Installing this release does not consent to migration, private-key sharing or a remote deployment.
