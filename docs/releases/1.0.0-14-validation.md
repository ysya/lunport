# Beta 14：介面一致性與動態

2026-10-16 已發布 [Beta 1.0.0-14](https://github.com/ysya/sshelter/releases/tag/v1.0.0-14)，固定來源為 `eed6881db0aab51420bb45b16247df58dcd7e221`，分支 `codex/library-sync-host-dialog-fixes`。本版沿用 Beta 通道，不以介面改版代表完成整份視覺規格。

## 內容與本機驗證

- 共用工作區頁首、列表／詳情、表單區塊、操作列與獨立決策視窗。側欄、Group 和詳情使用共用 motion tokens；新增 System／Reduced 偏好。
- 保留主機、金鑰、同步、匯入、遷移和信任問題的既有同意及可用性條件；未修改 Rust、SSH 引擎或同步協定。
- TypeScript、Vite production build、前端 82 檔／1,063 案例通過；其中發布版號與通道腳本的 46 案例另行確認。正式 bundle 不含開發假資料入口。Vite 保留既有 chunk size 提示。
- macOS Development app 使用正式前端產物完成 debug 原生 bundle。實際 `tauri://localhost` WebView 可繪圖；側欄展開／收合、主機詳情關閉與返回列焦點、編輯器／設定與操作列、17px 及 Reduced 切換、選單卸載通過。偏好恢復 System theme、15px、System motion，應用程式正常退出；本機 log 記錄 `exit`。
- 原生視窗檢查為 1100×720；800×560、深淺色、15／17px 和快速重開等矩陣另由真實元件的假資料瀏覽器入口驗證。[原生 17px 畫面](1.0.0-14-review/screenshots/macos-native-17px.jpg)。
- 完整內容及後續範圍見[實作紀錄](../2026-10-16-ui-consistency-implementation.md)。

## 限制

Legacy、部分設定與部署等次要畫面的全面整理仍屬後續工作；未完成 Windows／Linux 的逐畫面人工視覺驗收。這次本機原生驗證使用隔離 Development profile 和既有 disposable fixture，未透過這些畫面執行真實伺服器連線、私鑰分享或同步建立。
