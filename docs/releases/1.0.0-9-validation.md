# Beta 9：主機操作、同步提示與介面整理

基於已發布的 Beta 8（`49239cb267c0429e74ff4d1f4afb5a3edbbbc63f`），分支為 `codex/host-menu-sync-feedback`。

- 主機卡支援右鍵與 Shift+F10，可連線、編輯、複製地址、移入 Group、加標籤及刪除。
- 整理與刪除沿用已存主機的 ID／版本；有未存草稿時停用。刪除先確認，預設焦點在取消；資料改變後必須重新檢視。
- 關閉確認視窗會回到主機卡；刪除後回到剩餘卡片或主機列表。
- 同步中顯示進度；未完成的設定提供 Resume，單純暫停不標紅。重試期間保留前次錯誤，整輪結束後才依結果顯示錯誤。
- 修正建立 Library 時與背景同步交錯，將略過輪次誤判為帳戶需要檢查的問題。設定流程仍必須完成完整帳戶與子鏈驗證。

- 命令選單按內容決定寬度，長選項有視窗上限；Select 保持與欄位對齊。
- Connection details 預設 400 px，可拖曳至 320–640 px，並記住偏好；方向鍵、Home／End 與雙擊重設可用。縮小視窗只暫時限制顯示寬度。
- 灰階底色與少量藍色重點統一到全域主題；主畫面、卡片、選單和表單共用同一組色彩。
- 捲軸統一為透明軌道、圓角細滑塊，hover／拖動時加強提示；原生與 Radix 捲軸採相同設定，高對比模式保留系統尺寸／顏色。

Groups 自 Beta 5 起就屬於統一 Library。正常啟用 Sync 後，Hosts、Groups、階層與預設設定一起同步；尚待納入或需檢視的舊本機記錄仍留在本機。這次沒有改同步格式、加密方式或 relay。

## 本機驗證

- `npm test`：80 個檔案、1,056 項通過。
- `npm run build`：通過；既有的大型 bundle 提示仍在。
- CI 同等的安全 Rust suite：2,561 項通過，10 項排除（系統 Keychain 與 PAM）。
- Library 競爭問題先重現失敗，再修正通過；另以兩個真正交錯的執行緒確認必要同步會完成核對，且 activity 不會寫入狀態檔。
- Groups 在另一台假裝置下載、套用繼承與離線修改後同步的現有測試通過。
- 這台 macOS 的系統代理會攔截 HTTP fixture。重跑僅替測試程序設定 `NO_PROXY=127.0.0.1,localhost,::1` 與同值的 `no_proxy`；未變更系統設定或產品代理行為。
- 主機／同步修正的獨立 scoped review 已完成；UI 範圍另做一次獨立複查。兩項重要發現（無移動的分隔線操作覆寫偏好、長子選單超高）已重現並修正；高對比 Radix hover 樣式也一併補齊，沒有延後的 review 項目。

## 畫面驗證

使用實際 React 元件與公開假資料，沒有操作使用者主機、chain、vault 或剪貼簿。

- 右鍵與 Shift+F10、連線／編輯的 saved ID、複製地址的 native 呼叫參數。
- 移入 Group、加標籤及刪除的 ID／版本；草稿保護與取消不送出操作。
- 確認預設取消；取消後回原卡片，刪除後回剩餘卡片。
- 同步中及待續設為 0 個 alert；真正失敗為 1 個 alert。
- 帳戶檢查清掉後端錯誤、但同步尚未完成時，仍保留前次錯誤；整輪完成後清除。

- 完整 Records 工作區在 800×560、1100×720、1600×900 檢查深淺主題、主機／Group 編輯、設定、選單與底部狀態列，未見頁面水平溢出。另檢查 17 px 字級與 830 px 邊界。
- 小按鈕觸發的選單由 120 px 改為內容寬 180 px；長 terminal 選項限制於 240 px，800 px 視窗內未溢出。設定的 Text size Select 與 150 px 欄位對齊。
- 實際拖曳 400→560、Escape 取消、拖動中關閉、主機切換、重載記憶、Home／方向鍵／雙擊重設均通過。寬視窗可到 640 px；1100 px 視窗限制至 577 px 且列表保留 320.5 px。
- 640 px 偏好在窄窗顯示 577 px 時，單擊或按無效果的方向鍵不再覆寫偏好；放大後仍恢復 640 px。40 項長子選單現在限制於 560 px 視窗，End 可捲至最後一項。
- 大字級使內容區低於 640 px 時，改為單欄 Details，關閉後回列表，避免兩欄擠壓；焦點移到 Close details，偏好寬度保留。
- Settings 內容捲動 127 px，整頁維持 0；編輯器的標頭／動作仍在視窗內。捲軸實測 8 px 軌道、兩側各 2 px 透明留白與圓角滑塊；forced-colors 恢復 auto 尺寸和 CanvasText。
- 修正標準 scrollbar-width／scrollbar-color 蓋過 WebKit 圓角樣式的互斥；依 [MDN 說明](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/scrollbar-color) 分開 fallback 與 WebKit 規則。
- 額外檢查 Keys、Import、Sync、MCP 與 Updates 頁。160 字元無斷點的 Select 選項於 360 px 內換行，選取後 120 px trigger 以省略號顯示且未溢出。
- 主要按鈕文字對比：淺色 6.70:1、深色 7.41:1；淺色選取文字 5.37:1、導覽次要文字 4.75:1，深色選單次要文字 6.87:1。這是指定色對檢查，非整個應用的無障礙認證。
