# Beta 12：指紋核准與遷移後 Library sync

安裝包來源為 `99fb2ed7a09f0029b5417a56a7b911f4f911bbaa`，分支 `codex/library-sync-host-dialog-fixes`；包含 `995ceef` 的指紋競態修補與 `99fb2ed` 的舊版保留資料相容性修補。後續文件提交不改變安裝包來源。Beta 11 的安裝包不包含這兩項修補。

## 行為

- 指紋核准後，正常背景同步不再因全域狀態 generation 更新而中止連線。對最新狀態原子地核對本次核准相關身分並保存 pin，保留無關變更與同步 receipts。端點、路由、帳號、relay、金鑰或既有 pin 變更仍拒絕；取消／撤權與 Auto-log 不自動信任規則維持。
- Library sync 可包含存有已認證舊版 alias／text 來源記錄的 chain。保留其原始密文，不合併或改寫記錄身分。未知／無法認證格式及 typed ID shadow 仍拒絕，缺少下載基準與身分不可讀有不同提示。
- 沿用 Beta 11 的連線編輯器與 Records MCP `create_host`／`verify_host_key`。更新後重新連線或重啟 MCP client 以刷新工具清單；新／變更指紋仍須使用者在 SSHelter 明確核准。
