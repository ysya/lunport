# SSHelter 1.0.0 正式版驗證

[Stable 1.0.0](https://github.com/ysya/sshelter/releases/tag/v1.0.0) 已於 2026-10-17（Asia/Taipei）發布，Stable／Beta 更新通道均為 1.0.0。正式版來源為 `be39161f970a0c93dac1eb71fd6d89c6f678e72b`。功能透過 [整合 PR #25](https://github.com/ysya/sshelter/pull/25) 進入 main；[版本 PR #19](https://github.com/ysya/sshelter/pull/19) 在最終三組 CI 通過後於 2026-10-17（Asia/Taipei）合併一次，觸發正式版發布。合併來源與已驗證候選 `574101545432201fe4be309ff4464d0d9d0a7c1d` 的完整 Git tree 同為 `adf45b51822a6dac816aa9aa524ac33b78a68785`，見[來源收據](1.0.0-review/publication/source-verification.json)。

## 本版內容與金鑰選檔

- 納入 Beta 1–15 的 Records library、Groups、SSH engine、encrypted library sync、明確 Legacy migration、信任及金鑰分享控制，以及設定／Legacy／次要畫面的介面統整。之前的介面與原生檢查見 [Beta 15 驗證](1.0.0-15-validation.md)。
- Records 的 Keys → Import private key 預設提供 From a file，可開啟系統檔案選擇器，也保留 Paste key。無副檔名的檔案可選，合法檔名會預填名稱。
- 選檔只傳遞路徑；Rust 以既有 bounded regular-file reader 讀取最多 1 MiB，私鑰 bytes 與文字保持 zeroizing lifetime，再走現有 Local vault publication。來源檔不刪除、不改寫，金鑰預設不同步，回傳與 Query cache 僅含公開 overview。
- 只接受既有支援的 OpenSSH 私鑰。公鑰、PuTTY、PEM、非 UTF-8、非檔案與超過上限的來源會被拒絕。保留 busy、關閉確認、失敗重試、草稿與清除條件；匯入視窗沿用共用可捲動內容及固定操作列。

## 本機驗證

- TypeScript、production build、84 個前端測試檔／1,071 案例通過。正式產物排除 development fixtures；保留既有 Vite chunk size 提示。
- Record key Rust tests 19 passed，包含明文／加密檔案的 Local vault copy、來源不變、無效／過大／非 UTF-8／公鑰拒絕及 Unix symlink 保留。既有同步與加密 publication recovery 測試同時通過。
- 瀏覽器確認 From a file 預設、選檔及名稱帶入、切頁保留、只提交目前來源、完成返回列表與焦點。
- macOS Development 實際 `tauri://localhost` 開啟系統選檔視窗，取消後保留表單；選取臨時無副檔名 OpenSSH 私鑰並成功匯入，顯示 Local key／This device only。來源 SHA-256 與大小前後相同。重新開啟時名稱／路徑草稿已清除；完成焦點返回 Import private key，應用程式正常退出。
- 此次建立的 `disposable_import_validation` 僅留在 Development vault，未對應任何真實伺服器或帳戶；未安裝 Production 版本。見[驗收收據](1.0.0-review/key-file-validation.json)、[原生選檔畫面](1.0.0-review/screenshots/macos-native-key-file-import.png)、[原生完成畫面](1.0.0-review/screenshots/macos-native-key-import-complete.png)。

## 驗證限制

Windows／Linux 逐畫面原生人工驗收仍未完成。Windows 原生 GUI 啟動 CI 使用 placeholder 前端，安裝器檢查涵蓋產物及 console pair，兩者都不代表完整 React 畫面驗收。本機原生 UI 驗證使用 Development profile 與臨時測試金鑰，未透過畫面執行真實遠端連線、部署、帳戶／同步建立或私鑰分享。
