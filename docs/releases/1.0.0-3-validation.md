## 自動更新與裝置界線

正常 Records／Legacy 工作區在非 Dev 版本、自動檢查開啟且選擇 Beta 通道時，不必打開設定面板就會檢查：啟動約 5 秒、執行中每 4 小時、回到視窗最多每小時一次。更新通知仍需按 Install & restart；不會靜默安裝。通道預設 Stable，安裝 Beta 不會強制改成 Beta。

若使用者仍在沒有設定入口的 Beta 1 Records 畫面，那版也未掛載自動檢查，需手動安裝新版一次。Beta 2 起已補回。來源與條件見 [updater verification](1.0.0-3-review/updater-verification.md)。未讀取使用者目前安裝版本或偏好，沒有宣稱裝置已更新。

這次核對是公開 metadata／簽章檔一致性，未另外下載所有安裝包做獨立密碼學或內容驗證。使用者 Windows native select popup、OS 憑證／剪貼簿、睡眠恢復、真實主機／跳板的認證／指紋／公鑰部署、兩台真實裝置同步與 Beta 安裝重啟仍是裝置驗收。

保留既有 dead-code warnings 與 Vite chunk advisory。Auto-log 的免提示既存憑證讀取僅 Windows 有已驗證實作，macOS／Linux 需要憑證時要求 Ask；公鑰安裝僅支援 POSIX 遠端。首次 Groups／繼承需明確格式升級並先停止或更新舊客戶端；state 備份不等於 vault／OS 憑證備份。

Relay 最後只讀核對為 0.2.0／pull-batch／freeze，本次未部署 relay。四平台建置均確認 `SSHELTER_RELAY_URL` 未設定，因此本版沒有內建 relay 預設；既存設定保留，新安裝需自行填入 HTTPS relay。[建置摘要](1.0.0-3-review/publication-build-summary.txt)。

[功能檢視清單](1.0.0-3-review-checklist.md) 與 [遠端接手文件](../2026-10-15-beta3-remote-handoff.md) 保留操作入口、視覺證據與其餘限制。
