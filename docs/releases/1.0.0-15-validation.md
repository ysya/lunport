## 內容與來源驗證

- 設定改為 Application／Workspace／Maintenance 三組導覽與可搜尋區塊；Records 7 個分類、Legacy 8 個分類。偏好轉移、診斷、AI access 和工作區工具依用途歸位。
- Config path 草稿跨分類及搜尋保留，關閉前確認，載入期間保留視窗；Legacy Sync 草稿在設定視窗內切頁保留。保留明確的 Apply／Save 與匯入確認。
- Legacy、Keychain、部署、同步審閱、資料維護與 MCP 視窗共用標頭、內容捲動及固定操作；補齊 disclosure、焦點還原、錯誤與重試。
- 本機 TypeScript、Vite production build、83 個前端測試檔／1,066 個案例通過。正式產物排除 development fixtures；保留既有 chunk size 提示。46 個來源檔 SHA-256 與已驗證來源相符；未變更 Rust、SSH 引擎或同步協定。
- 代表性瀏覽器檢查包含 800×560／17px／dark／Reduced、1100×720／15px／light／System、1440×900／13px／light／System；不是所有狀態的完整笛卡兒積。
- macOS Development 原生設定檢查包含搜尋跳轉、分類切換、15／17px、System／Reduced、選單卸載及關閉焦點；偏好還原後正常退出。最終前端產物也完成原生啟動檢查。
