## 使用前須知

- 首次 Group／繼承會要求格式升級確認，先保存受保護的本機 state 備份；共享資料需升級 account schema 4。請先停止或更新其他舊客戶端。備份是 record state，不包含 vault 與 OS 儲存的密碼備份；不能只還原本機檔案來撤回共享升級。
- Chain 是參考 Brave 的免帳號同步概念。Vault 與 master key 留在裝置；relay 保存端對端加密的共享 records 及明確選擇共享的私鑰。SSH 密碼／passphrase 留在各裝置。不是區塊鏈。
- Auto-log 的免 OS 提示儲存憑證讀取目前只支援 Windows。macOS／Linux 需要憑證的 Auto-log 請求會拒絕並要求 Ask；不能把顯示核准視窗當成已解除背景憑證限制。
- 公鑰安裝支援 POSIX 遠端；Windows 客戶端可以連 POSIX，遠端 Windows 帳號安裝尚未支援。送出後若斷線／取消／逾時，應先檢查遠端檔案再重試。
- MCP 的 OS IPC 確認同一使用者的來源，無法隔離同一 OS 使用者的其他程式；加入 Group 不會自動授予整組 AI 權限。
- 修改 sync code 不會撤回舊 code 可讀的歷史密文，也無法收回已下載的資料。
- 使用者提供的 relay `/v1/info` 已只讀核對：0.2.0、pull-batch／freeze；本次不需要更新 relay。
