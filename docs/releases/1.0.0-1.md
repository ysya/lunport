# SSHelter 1.0.0-1 (beta)

This beta introduces the record-based SSH workspace and accountless sync chains. Each device keeps its encrypted vault and master key locally. The relay stores end-to-end encrypted host records and explicitly selected private keys; SSH passwords and key passphrases stay on each device.

## Changes

- Stable host IDs, host editing and Local/space moves, with the built-in SSH engine, jump routes, endpoint-bound host-key trust, CLI and tray integration.
- Local key import/generation by default; explicit encrypted key publication, download and vault activation.
- Sync-chain creation/join, space selection, resumable operations and forward-format protection.
- Read-only SSH configuration import previews, and explicit resumable migration from v1/v2 legacy state.
- Leave an account while retaining available hosts and local key material; change the sync code through relay-supported freeze and a new chain.
- Native controls for hosts, keys, accounts, imports, migration, leave and code rotation.

## Before migrating

Existing legacy data opens paused. Review the preview and explicitly confirm migration; installing this beta does not silently convert your account. Stop older clients or update them to a version with forward-format protection before confirming migration. This beta cannot prove that every offline old client has been updated.

Original configuration/key sources and protected migration backups are retained. Do not downgrade migrated v3 state to unpatched older clients: older versions may move it to an unreadable backup and leave the sync account. A completed network migration cannot be undone by restoring local files alone.

## Limitations

Records-mode MCP remote execution and key deployment remain unavailable until phase 2. This is the minimum records workspace, not full Termius feature parity.

Changing the sync code routes future updates to the new chain. The old code can still read frozen historical ciphertext, and previously downloaded data cannot be revoked. Private keys are local by default; anyone holding a sync code can access the records and keys shared into that chain.

If this build has no built-in relay, enter your relay URL in Sync account before creating or joining a chain. External relay URLs require HTTPS; localhost is allowed for development.

This is a prerelease offered through the Beta update channel. It does not replace the Stable release.
