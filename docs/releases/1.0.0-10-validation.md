# Beta 10：macOS 原生啟動保護

應用來源固定為 `4a210eb449d842a84a119500e88cb39118a00c1a`，分支為 `codex/macos-coreaudio-startup-guard`。此提交包含修補 `f9ad05afe79452f4d1deb112d06971c7b6934a48`；後續收據文件不改變安裝包來源。

## 行為與限制

- macOS 建立 WebView 前，以有期限、可終止及回收的子程序查詢 CoreAudio。錯誤或逾時顯示 AppKit 原生提示，可明確重試、保留診斷或維持背景運作。
- 主視窗與 authentication／hostkey／approval 視窗共用保護；背景 broker、CLI Connect、MCP stdio 及 ASKPASS 不依賴這項 GUI 檢查。
- WebContent 結束後，以使用者明確選擇取代預設自動 reload；每個 window label 每次 app 執行最多允許一次重載。GPU 停滯另行處理，原生 Help／tray 診斷仍可使用。
- 檢查失敗保留既有視窗與草稿，拒絕待處理安全提示，不新增信任或記住核准。WebContent 本身死亡仍可能遺失純記憶體草稿。

這是**避免可偵測的啟動前故障變成無提示黑畫面**的保護，不是根除系統音訊死鎖。檢查通過後才發生的 GPU／CoreAudio 故障仍可能造成黑畫面。原始音訊卡住原因未確定，不能歸咎特定應用程式。
